# Prompt: Explain and Verify

适合 AI 已经写了代码，但你看不懂时使用。

```text
请解释当前实现，但不要只给顺滑总结。

请按以下结构输出：
1. 从代码直接可见的事实。
2. 基于语言规则或框架规则的推断。
3. 你不确定、需要验证的假设。
4. 数据流或控制流的逐步说明。
5. 关键不变量。
6. 如果这段代码错了，最可能错在哪里。
7. 哪些测试能证明它真的满足需求。
8. 我作为不熟悉这个技术栈的人，应该优先读哪些 20-50 行。

请不要修改代码。
```

理解检查题：

```text
请基于刚才这段代码，给我 5 个理解检查问题。

要求：
1. 问题必须能暴露我是否真的理解代码。
2. 至少 2 个问题涉及边界条件或失败路径。
3. 如果是 Rust，至少 2 个问题涉及 ownership / borrowing / error handling。
4. 不要直接给答案。

我回答后，你再逐题点评。
```
