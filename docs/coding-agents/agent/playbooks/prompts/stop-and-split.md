# Prompt: Stop and Split

适合 agent 已经越改越大，或者你开始看不懂 diff。

```text
停。当前 diff 已经超过我能 review 的范围。

请不要继续实现，也不要继续重构。

现在请做三件事：
1. 总结当前 diff 里包含了哪些不同类型的改动：功能、测试、重构、格式化、依赖、文档。
2. 把这些改动拆成 3-5 个 reviewable slices。
3. 建议哪些改动应该保留，哪些应该回退或延后。

每个 slice 请说明：
- 目标。
- 涉及文件。
- 预计 diff 大小。
- 测试方式。
- 回滚方式。

在我确认前，不要修改文件。
```

执行前范围声明：

```text
执行前请先声明本轮范围：
1. 本轮要改什么。
2. 本轮不改什么。
3. 预计修改哪些文件。
4. 预计 diff 大小。
5. 需要运行哪些验证。
6. 如果超过范围，你会在哪一步停下来问我。

等我确认后再开始。
```
