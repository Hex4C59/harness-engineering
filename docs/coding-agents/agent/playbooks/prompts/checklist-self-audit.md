# Prompt: Checklist 自检

适合让 agent 按指定 checklist 检查当前结果、补齐遗漏并给出验证证据。

```text
请阅读：

- <checklist-path>

然后对当前结果做一次 checklist 自检。

请列出：
- 已完成项
- 缺失项
- 需要修正的项

如果有缺失，请在不扩大范围的前提下直接补齐。

注意：
- 不要删除或覆盖用户已有内容。
- 不要做 checklist 范围之外的业务改动。
- 如果 checklist 涉及已预置的工具箱、模板或用户资料，默认保留现有内容，不要重复复制或覆盖。
- 修正完成后运行当前可用的最小验证命令。
- 最后检查 git status，并说明仍未完成或需要人工决定的事项。
```
