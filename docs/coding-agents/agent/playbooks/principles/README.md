# Principles

这里保存长期稳定的判断框架。它们不是 prompt，也不是项目模板，而是解释为什么要这样组织 coding agent 工作流。

| 原则 | 用途 |
|---|---|
| [`task-document-layers.md`](task-document-layers.md) | 区分 Roadmap、Spec、Execution Plan 和 Project Status |
| [`reviewable-slices.md`](reviewable-slices.md) | 控制 diff，使它可 review、可测试、可回滚 |
| [`tdd-and-verification.md`](tdd-and-verification.md) | TDD、失败测试和完成声明规则 |
| [`dependency-and-architecture-changes.md`](dependency-and-architecture-changes.md) | 依赖和架构变化的审批感 |
| [`learning-first.md`](learning-first.md) | 陌生技术栈下避免学习债 |
