# Templates

这里保存可以复制到新项目里的文件模板。新项目初始化时优先使用这些模板，再按具体技术栈补充。

| 模板 | 用途 |
|---|---|
| [`project-harness-files.md`](project-harness-files.md) | `AGENTS.md`、`README.md` 和 `docs/*.md` 模板 |
| [`scripts.md`](scripts.md) | `scripts/bootstrap`、`scripts/dev`、`scripts/test`、`scripts/check` 约定 |
| [`existing-project-agents.md`](existing-project-agents.md) | 既有项目的最小 `AGENTS.md` 模板 |
