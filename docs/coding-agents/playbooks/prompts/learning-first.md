# Prompt: 学习优先开场

适合刚开始用 AI 写陌生语言或陌生框架。

```text
我想用 coding agent 实现这个项目，但我的目标不是只拿到代码，而是边做边学。

我的背景：
- 我熟悉：
- 我不熟悉：
- 当前想学习的技术栈：

项目目标：
暂时不做：
风险边界：

请按以下原则工作：
1. 每次只做一个 reviewable slice。
2. 每个 slice 先解释涉及的核心概念，再给一个 30 行以内的 tiny example。
3. 在 tiny example 后，先问我 2-3 个理解检查问题。
4. 我确认后，再进入项目代码。
5. 单次 diff 默认不超过 80 行。
6. 不要顺手重构、换库、改名或格式化无关文件。
7. 如果必须扩大范围，先停止并解释原因，不要继续改。
8. 完成后输出：改了什么、为什么这样改、如何验证、我应该重点 review 哪几行。

请先不要改代码。
先给出第一个最小 slice 的计划。
```
