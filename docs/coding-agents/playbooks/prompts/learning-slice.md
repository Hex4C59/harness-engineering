适合已经确认 slice，准备在陌生技术栈中小步实现。

```text
现在只执行这个 slice：

slice 名称：
目标行为：
非目标：
允许修改文件：
测试方式：
diff 上限：

请按顺序执行：
1. 先用 30 行以内 tiny example 解释本 slice 的核心概念。
2. 问我 2-3 个理解检查问题。
3. 我确认后，先写或更新测试。
4. 再写最小实现。
5. 跑相关测试或检查。
6. 做 diff review。
7. 停下来，不要自动进入下一个 slice。

如果你发现需要改更多文件或超过 diff 上限，请停止并重新拆分。
```
